# Portfolio Website

This is a personal portfolio website to showcase my projects, research, publications, and contact information. It is designed to be clear, responsive, and easy to navigate.

## Project Structure

```
Portfolio/
├── document/                 # Additional documents
├── images/                   # Image assets
├── about.html                # About me page
├── blog.html                 # Blog or updates
├── contact.html              # Contact details
├── index.html                # Homepage
├── license.html              # License information
├── projects.html             # Project listings
├── publications.html         # Research publications
├── README.md                 # Project description
├── research.html             # Research highlights
├── scripts.js                # JavaScript functionality
└── styles.css                # Main stylesheet
```

## Features

- Simple and professional layout  
- Mobile-responsive design  
- Sections for projects, research, blog, and publications  
- Easy customization

## Getting Started

To view the website locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/RohanNathHERE/Portfolio.git
   cd Portfolio
   ```

2. Open `index.html` in any web browser.
