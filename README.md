# Rohan Nath Portfolio

A personal portfolio website showcasing my research, publications, projects, and contact information. Designed to be clean, responsive, and user-friendly.

## Features

- Professional and minimalistic design
- Fully responsive for mobile and desktop
- Sections for About, Research, Publications, Projects, Blog, and Contact
- Easy to customize

## Project Structure

- `images/`: Image assets
- `document/`: Additional documents
- `index.html`: Homepage
- `about.html`: About me
- `research.html`: Research details
- `publications.html`: Publication list
- `projects.html`: Project showcase
- `blog.html`: Blog or updates
- `contact.html`: Contact information
- `license.html`: License details
- `scripts.js`: JavaScript functionality
- `styles.css`: Main stylesheet

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/RohanNathHERE/Portfolio.git
   cd Portfolio
   ```

2. Open `index.html` in a web browser to view the website locally.
